## 功能

| 功能 | 说明 |
| --- | --- |
| 🪙 赚金币 | 自动进入淘宝淘金币页面，兼容 2026 双十一赛车首页左侧「去赚金币」入口及旧版入口；沿用原金币任务引擎 |
| ⚡ 双11赚能量 | 自动进入赛车首页右侧「去赚能量」入口，识别「做任务赚能量」任务列表，执行可支持的浏览、滑动、搜索任务 |
| 搜索类任务 | 在双十一「搜一搜你喜欢的宝贝」场景识别搜索发现/历史搜索，点击推荐项、浏览并返回复查进度 |
| 考试任务 | 对符合结构证据的淘金币考试识别 A/B 等选项并提交，按页面反馈判断结果 |
| 共享任务规则 | 金币和能量共用黑名单、跨应用、搜索、浏览规则；新增默认跳过词与已有配置的非破坏性迁移 |
| 状态与日志 | 顶部可选悬浮状态条、停止/原地重新开始、可滚动并自动跟随最新的日志、复制/清空日志 |
| 安全行为 | 对无法认证的页面避免盲目点击；碰到安全验证时停止，不尝试绕过 |

技术链路：**Shizuku 截图 → ML Kit 中文 OCR → 状态机判断 → Shizuku 点击/滑动/返回**。无需 Root 或安卓无障碍服务（Shizuku 需要按其正常流程授权）。

## 安装与使用

1. 安装并启动 [Shizuku](https://github.com/RikkaApps/Shizuku)，确认设备上的 Shizuku 服务正常运行。
2. 安装本 Fork 对应版本的 APK，启动 App 并授予 Shizuku 权限；确保已安装、登录淘宝。
3. 可选启用「顶部悬浮状态条」并授予悬浮窗权限。
4. 按需点击「🪙 开始执行赚金币」或「⚡ 开始执行双11赚能量」。运行中可停止；停止或异常后可在当前页尝试「重新开始」。
5. 在「任务规则设置」里检查黑名单，首次使用建议看着手机运行；若出现异常，以最新日志与真机画面为准。

### 安装包与更新限制

当前 GitHub Actions 采用 **Debug APK 构建**，使用构建环境的临时调试签名，**不是长期维护的正式 Release 签名**。不同构建批次可能无法覆盖升级同一包名（Android 签名不一致）；切勿为升级而直接卸载，除非已经确认如何保留或恢复个人规则。待建立稳定签名和确认原项目授权后，再考虑公开分发稳定签名 APK。

此 Fork 使用 `com.layerverse.taobaocoinassistant`，可与原版应用并存。按设备 CPU 架构选择对应产物；小米 13 Ultra 使用 `arm64-v8a`。

## 构建

项目为 Android/Gradle 工程。仓库已包含 `.github/workflows/build-apk.yml`，可以通过 GitHub Actions 构建 Debug APK；也可在配置好 Android SDK、JDK 17 的本地环境使用 `./gradlew :app:assembleDebug`。
